A virtual weather-station device which gives random readings of temperature, humidity, pressure which change every 10 seconds and a weather
mode which changes every 60 s. It has three Flow cards: A trigger card, which fires when the weather mode changes to a selected mode, a 
condition card for when it is or is not raining, and an action card which writes the mode capability on the selected device. A widget is also
added to the app which displays the temperature, humidity, pressure and mode. The app also comes with a settings page so the values of 
the capabilities can be frozen.
